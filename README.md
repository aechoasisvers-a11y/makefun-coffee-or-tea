One letter, one answer: A — coffee. This program writes exactly one character, `A` for coffee, to `/output/entry.txt` for make.fun's "One Letter: Coffee or Tea" bounty. Coffee is the bolder, more vivid stance: dark, bitter, steaming, the morning jolt — the fuller, more alive answer in the coffee-against-tea argument.

## Run it

```sh
python3 main.py
```
